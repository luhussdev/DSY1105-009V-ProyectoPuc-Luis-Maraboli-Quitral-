# 7. Registro de Prompts de IA Generativa (Apoyo GenAI)

En conformidad con las pautas del Checkpoint VcM - EV2, se documenta el uso de Inteligencia Artificial Generativa como herramienta de apoyo para la estructuración y reformulación de artefactos técnicos.

## Prompts Utilizados durante la Sesión de Trabajo

### Prompt 1: Análisis y Consolidación del Caso CIM UC
> *"Actúa como Tech Lead. Realiza el análisis del caso CIM UC (Centro UC de Innovación en Madera) para el MVP en Android Kotlin Jetpack Compose. Define problema, usuarios, alcance, entidades, diagrama de flujos, riesgos y matriz RF vs RNF."*

### Prompt 2: Generación de Artefactos de la EV2 en Archivos Separados
> *"Como parte del desarrollo del proyecto de Vinculación con el Medio (VcM), la entrega exige 6 archivos independientes: Replanteamiento del caso, Requerimientos de alto nivel, Requerimientos funcionales/no funcionales, Casos de uso e historias de usuario, Modelo de datos preliminar y Mockups del flujo. Genera el texto técnico exacto para cada uno manteniendo estricta coherencia."*

### Prompt 3: Comandos de Estructuración en Git y Naming
> *"Ayúdame con los comandos Git para subir la carpeta Checkpoint_VcM_EV2 a mi repositorio ProyectoPuc de forma limpia y ordenada."*

## Declaración de Responsabilidad del Equipo
El equipo comprende, valida y asume la responsabilidad total sobre el contenido, la arquitectura MVVM propuesta, el modelo de datos Kotlin y las decisiones de diseño expuestas en este Checkpoint, estando en capacidad de justificar cada decisión técnica ante el docente.
